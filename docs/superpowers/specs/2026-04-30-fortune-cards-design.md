# 解读卡片样式重构设计文档

日期：2026-04-30

## 背景

当前各功能模块（八字、塔罗、解梦等）的 AI 解读结果使用折叠式卡片组件。用户希望改为类似「测测App」的运势卡片样式。

## 设计目标

复刻测测App的运势卡片设计，包括：
- 彩色标签胶囊（事业、人际、爱情等）
- 大标题 + 进度条装饰 + 副标题时间
- 正文内容截断 + 全文展开
- 底部讨论区信息栏

## 最终设计

### 卡片结构（从上到下）

```
┌─────────────────────────────┐
│ ┌─────┐ ┌─────┐            │  ← 标签区（彩色胶囊）
│ │事业▼│ │人际▼│            │
│ └─────┘ └─────┘            │
├─────────────────────────────┤
│ 紧迫感拉满                   │  ← 主标题（大字号粗体）
│ ────────────                │  ← 进度条装饰
│ 火星六合天顶      今天开始   │  ← 副标题 + 时间（两端对齐）
├─────────────────────────────┤
│ 在这段时间，工作中有较多紧迫  │  ← 正文内容
│ 感，有些马不停蹄干不完活的... │
│ 流露在外自信和 ...全文        │  ← 超出截断 + "全文"链接
├─────────────────────────────┤
│ 同类交流地 · 1927测友正在讨论>│  ← 底部信息栏
└─────────────────────────────┘
```

### 组件设计

#### 数据结构

```javascript
{
  id: String,              // 卡片唯一标识
  title: String,           // 主标题
  subtitle: String,        // 副标题（左侧）
  tags: Array<{             // 标签列表
    type: String,          // 标签类型（事业/爱情/等）
    name: String           // 显示文字
  }>,
  status: {                // 状态信息（右侧）
    text: String,          // 显示文字
    color: String          // 可选自定义颜色
  },
  content: String,         // 正文内容
  maxLines: Number,        // 最大显示行数（默认3）
  footer: {                // 底部信息
    icon: String,          // 图标文字
    text: String,          // 主文字
    count: Number,         // 数量
    action: String         // 动作文字
  },
  expanded: Boolean        // 是否已展开
}
```

#### 组件属性

```javascript
Component({
  properties: {
    card: Object,           // 卡片数据（符合上述结构）
    showFooter: {           // 是否显示底部信息栏
      type: Boolean,
      value: true
    },
    showProgress: {         // 是否显示进度条
      type: Boolean,
      value: true
    }
  },

  data: {
    isExpanded: false,      // 内部展开状态
    isTruncated: false      // 内容是否被截断
  }
})
```

#### 交互行为

1. **点击全文**：展开显示完整内容
2. **再次点击**：收起回到截断状态
3. **点击标签**：可触发筛选或导航（预留）
4. **点击底部栏**：跳转讨论区（预留）

## 技术实现

### 文件结构

```
components/fortune-card/
├── fortune-card.js
├── fortune-card.wxml
├── fortune-card.wxss
└── fortune-card.json
```

### 样式复用

卡片基础样式写入 `theme.wxss` 作为全局规范，组件内仅保留布局相关样式。

### 页面集成

各页面将原来的 `analysis-cards` 容器替换为 `fortune-card` 组件：

```xml
<view class="fortune-cards" wx:if="{{fortuneCards.length > 0}}">
  <fortune-card
    wx:for="{{fortuneCards}}"
    wx:key="id"
    card="{{item}}"
  />
</view>
```
