# 解读卡片样式重构设计文档

日期：2026-04-30

## 背景

当前各功能模块（八字、塔罗、解梦等）的 AI 解读结果使用折叠式卡片组件 `analysis-card`，交互为点击展开。用户希望改为更直观的新卡片样式。

## 设计目标

- 内容直接展示，无需点击展开
- 使用统一的浅金色主题风格
- 分组式布局：大标题区 + 多个小卡片
- 所有模块保持一致体验

## 最终设计

### 整体结构

```
┌─────────────────────────────────┐
│      [模块名称解读]               │  ← 大标题区（深金渐变背景）
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │ ○五 │ 五行分析               │ │  ← 小卡片1（白色背景）
│ │     │ 详细内容直接展示...     │ │
│ └─────────────────────────────┘ │
│ ┌─────────────────────────────┐ │
│ │ ○性 │ 性格特点               │ │  ← 小卡片2
│ │     │ 详细内容直接展示...     │ │
│ └─────────────────────────────┘ │
│ ┌─────────────────────────────┐ │
│ │ ○事 │ 事业运势               │ │  ← 小卡片3
│ │     │ 详细内容直接展示...     │ │
│ └─────────────────────────────┘ │
│ ...更多小卡片                   │
└─────────────────────────────────┘
      ↑ 外层容器（浅金色背景）
```

### 样式规范

**外层容器 `.interpretation-container`**
- 背景：`linear-gradient(180deg, #FDF8E8 0%, #F5EFE0 100%)`
- 圆角：`24rpx`
- 内边距：`24rpx`
- 阴影：`0 4rpx 20rpx rgba(184, 150, 46, 0.1)`

**大标题区 `.interpretation-header`**
- 背景：`linear-gradient(135deg, #B8962E 0%, #D4A84B 100%)`
- 文字颜色：白色
- 字号：`36rpx`，字重：700
- 内边距：`24rpx 32rpx`
- 圆角：`16rpx`（顶部）

**小卡片 `.interpretation-card`**
- 背景：`#FFFFFF`
- 圆角：`16rpx`
- 内边距：`24rpx`
- 间距：相邻卡片间隔 `16rpx`
- 阴影：`0 2rpx 12rpx rgba(0, 0, 0, 0.06)`

**图标 `.interpretation-icon`**
- 尺寸：`64rpx × 64rpx`
- 背景：金色渐变
- 圆角：圆形
- 文字：首字，白色，`28rpx`，字重 600

**标题 `.interpretation-title`**
- 字号：`32rpx`，字重 600
- 颜色：`#2A2A2A`

**内容 `.interpretation-content`**
- 字号：`28rpx`
- 行高：`1.8`
- 颜色：`#5A5A6A`
- 支持富文本（加粗、列表等）

## 技术方案

### 组件结构

保留 `analysis-card` 组件，完全重构内部实现：

```
components/analysis-card/
├── analysis-card.js      # 保留属性接口，移除折叠逻辑
├── analysis-card.wxml    # 新模板结构
├── analysis-card.wxss    # 新样式（可内联到 theme.wxss）
└── analysis-card.json    # 保持不变
```

### 属性变更

**移除属性：**
- `summary` - 不再需要摘要
- `expanded` - 不再需要展开状态

**保留属性：**
- `title` - 卡片标题
- `content` - 卡片内容（富文本）

**新增属性：**
- `icon` - 图标文字（默认取 title 首字）

### 页面改动

各页面需：
1. 将原来的 `analysis-cards` 容器改为 `interpretation-container`
2. 外层添加 `interpretation-header` 大标题区
3. 内部使用改造后的 `analysis-card` 组件

### 数据格式

保持现有 `analysisCards` 数据结构不变：

```javascript
{
  id: String,        // 卡片标识
  title: String,     // 标题
  content: String,   // 富文本内容
  icon: String       // 图标文字（可选）
}
```
