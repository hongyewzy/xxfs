# 玄学风水小程序重构设计文档

> **创建日期:** 2026-04-29

## 一、项目概述

**项目名称:** 天机阁 - 玄学风水小程序

**重构目标:** 统一所有页面视觉风格为浅金色星空主题，保留核心功能，增加每日运势推送

**涉及页面:** 8个（首页、八字、塔罗、梅花易数、解梦、姓名、起名、农历、历史）

---

## 二、整体视觉风格

### 2.1 配色方案

| 元素 | 颜色值 | 说明 |
|------|--------|------|
| 背景主色 | `#FDF6E3` → `#F5E6C8` | 浅金色渐变，从上到下 |
| 卡片背景 | `#FFFFFF` | 纯白 |
| 主强调色 | `#B8962E` | 金色 |
| 次强调色 | `#D4A84B` | 浅金色 |
| 文字主色 | `#2A2A2A` | 深灰近黑 |
| 文字次色 | `#666666` | 中灰 |
| 文字辅助 | `#999999` | 浅灰 |

### 2.2 背景效果

**星光点缀:**
- 随机分布 30-50 个小白点
- 大小 2-4rpx
- 随机闪烁动画（opacity 0.3-1，周期 2-4s）

**流星效果:**
- 从右上角不定时滑落（左上→右下轨迹）
- 持续时间 1.5s
- 长度 80-120rpx
- 颜色：白色→金色渐变
- 间隔：随机 8-15s 触发一次
- 所有 8 个页面均添加此效果

### 2.3 卡片组件

**结构:**
```html
<view class="card">
  <view class="card-decorator"></view>  <!-- 彩色渐变条 -->
  <view class="card-content">
    <!-- 内容区 -->
  </view>
</view>
```

**样式:**
- 背景: `#FFFFFF`
- 圆角: `32rpx`
- 阴影: `0 8rpx 32rpx rgba(184, 150, 46, 0.12)`
- 顶部装饰条: `8rpx`，渐变色（根据页面类型变化）
- 间距: `32rpx`

**内容区:**
- 大标题: `44rpx`，字重 `700`，颜色 `#2A2A2A`
- 摘要: `32rpx`，行高 `2.2`，颜色 `#666666`
- 底部数据: 点赞/评论数，图标+数字

**装饰条渐变色:**
- 首页: 金色 `#B8962E` → `#D4A84B`
- 八字: 金色 `#B8962E` → `#D4A84B`
- 塔罗: 紫色 `#8B5CF6` → `#A78BFA`
- 梅花易数: 绿色 `#10B981` → `#34D399`
- 解梦: 蓝色 `#3B82F6` → `#60A5FA`
- 姓名: 橙色 `#F59E0B` → `#FBBF24`
- 起名: 青色 `#06B6D4` → `#22D3EE`
- 农历: 红色 `#EF4444` → `#F87171`

### 3.2 每日运势卡片

**输入模式切换:**
- 顶部 Tab 切换：星座 / 八字
- 选择星座：12 宫选择器
- 选择八字：出生年份 + 出生月份（简化版）

**运势展示内容:**
- 今日运势等级（旺/衰）
- 幸运色
- 幸运数字
- 宜 / 忌
- 一句话点评

**八字运势生成规则:**
- 根据年柱天干确定五行倾向
- 配合当日日期生成简单运势

**星座运势生成规则:**
- 使用预设 12 星座运势模板
- 每周更新一次内容

## 七、技术实现要点

### 7.1 通用组件

**星光背景组件 (star-background):**
- 全屏覆盖的固定定位层
- 包含：背景渐变 + 星光点阵 + 流星动画
- 可复用至所有页面

**卡片组件 (style-card):**
- 统一的卡片样式
- 支持自定义顶部渐变色
- 可替代现有 analysis-card 部分功能

### 7.2 每日运势数据

**星座运势：**
- 维护 12 份每周运势模板
- 按周轮换

**八字运势：**
- 简化算法：根据年干五行 + 当日天干生成
- 预定义运势描述库
